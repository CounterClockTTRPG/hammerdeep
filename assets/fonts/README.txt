The interface fonts, shipped with the game. All are under the SIL Open Font
License 1.1; each family's licence is beside it. Taken unmodified from
https://github.com/google/fonts (ofl/).

  Cinzel.ttf                     titles and headings   Cinzel-OFL.txt (The Cinzel Project Authors; renamed from Cinzel[wght].ttf)
  Barlow-Regular.ttf             body text             Barlow-OFL.txt (The Barlow Project Authors)
  BarlowCondensed-SemiBold.ttf   small labels          Barlow-OFL.txt
  Inconsolata.ttf                numbers, the log      Inconsolata-OFL.txt (The Inconsolata Project Authors)

UITheme loads them as bytes; a missing file falls back to Godot's own font.
